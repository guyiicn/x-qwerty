# guyii社交

一个很薄的 Android WebView X（Twitter）客户端壳，为**带物理全键盘的 Android 手机**（黑莓式）做的键盘优先导航。

不调用 X API，不碰账号密码 —— 就是把 X 的移动版网页装进 WebView，外面套一层原生导航，里面注入一段脚本做键盘操作和版式调整。登录、数据、功能全部来自 X Web 本身。

零依赖：不用 AndroidX，不用任何第三方库，APK 44KB。

> 非官方项目，与 X Corp. 无关。

## 构建

```bash
./gradlew assembleDebug
```

APK 输出在：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 原生壳 UI

- 底部悬浮导航：`首页`、`搜索`、`Grok`、`通知`、`私信`、`我`，前五个带选中态和未读角标。
- 发帖是右下角浮动按钮，只在根页面出现；X 自己的浮动发推按钮被隐藏，避免两个重复。
- 发帖/回复框打开时底栏和发帖按钮一起让位，右下角换成 `发布`。
- `通知` 长按进 @我的。
- 再点一次当前所在的 Tab = 回到顶部并刷新，不重载整页。
- 抽屉：点底栏的 `我` 打开；也可以从屏幕左边缘右滑，或长按 `首页`（这两个在手势导航的设备上可能被系统返回手势吃掉）。里面是个人资料 / 书签 / 列表 / 社区 / 已喜欢 / 草稿 / 设置与隐私，底部有字号调节。返回键先关抽屉。
- 主题：抽屉底部有 `跟随` / `浅色` / `深色` 三个选项，直接切换整个 App（写 X 的 `night_mode` cookie 后重载，页面和外壳一起变），选择会记住。选 `跟随` 则沿用 X 自己「设置 → 显示」里的主题，Dim 也走这条。
- 时间线顶部 X 自带的发推框被隐藏，发帖统一走右下角按钮；详情页的回复框保留。
- X 自带的左侧导航栏和底部标签栏被隐藏；二级页的返回箭头保留可用。
- 全屏视频时隐藏所有原生浮层。

## 快捷键

面向**黑莓式安卓物理键盘**：有 `Alt`、有返回键，**没有 Ctrl、没有 F 键、没有 Esc、没有方向键**。下面按实际能按出来的顺序排，组合键在最后单列一段。

App 里也能查：抽屉 → `快捷键一览`。

### 单键（输入框聚焦时全部让路）

| 键 | 作用 |
| --- | --- |
| `b` / `f` | 后退 / 前进（`f` 是浏览器前进，需先后退过才有效） |
| `空格` / `⇧空格` | 下翻 / 上翻一页 |
| `j` / `k` | 下一条 / 上一条帖子 |
| `Enter` | 进入选中的帖子 |
| `u` | 刷新当前视图（回顶 + 拉新帖） |
| `.` | 整页重载 |
| `/` | 聚焦搜索框 |
| `n` | 发帖 |
| `l` | 赞 |
| `r` | 回复 |
| `t` | 转发 / 再按一次取消 |
| `q` | 引用转发 |

`j` / `k` 选中的帖子会有蓝色描边，`Enter` / `l` / `r` / `t` / `q` 作用在它身上。

打开列表页、刷新、切换标签之后会自动选中第一条，可以直接开始 `j` / `k`。选中项滚出视野后，`j` / `k` 从当前可见的位置继续，不会跳回去。

### 发布与关闭

| 键 | 作用 |
| --- | --- |
| `Alt+Enter` | 发布 |
| 返回键 | 关快捷键页 → 关抽屉 → 退全屏 → 关发帖框 → 后退 |
| 返回键 | 已在首页且无历史时，两秒内再按一次退出 App |

### `g` 前缀层（按 `g` 后 1.2 秒内接第二个键）

| 组合 | 作用 |
| --- | --- |
| `g h` | 首页 |
| `g n` | 通知 |
| `g m` | @我的 |
| `g d` | 私信 |
| `g s` | 搜索 |
| `g g` | Grok |
| `g p` | 个人资料 |
| `g b` | 书签 |
| `g l` | 列表 |
| `g k` | 已喜欢 |
| `g c` | 社区 |

### `z` 前缀层（字号）

| 组合 | 作用 |
| --- | --- |
| `z k` / `z j` | 字号 ＋ / − |
| `z 0` | 复位 100% |

### 触屏

| 操作 | 作用 |
| --- | --- |
| 点已选中的 Tab | 回到顶部并刷新 |
| 长按「通知」 | 进 @我的 |
| 长按「首页」 | 打开抽屉 |
| 左边缘右滑 | 打开抽屉（手势导航的机器上会被系统返回吃掉） |

### 只有外接全键盘能按

这些组合键代码里保留着，但黑莓式键盘按不出来，每条都有等效的本机按法。

| 组合 | 本机用什么代替 |
| --- | --- |
| `Ctrl+Enter` | `Alt+Enter` |
| `F5` / `Ctrl+R` | `.` |
| `Alt+←` / `Alt+→` | `b` / `f` |
| `Ctrl+L` | `/` 或 `g s` |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | `z` 前缀层 |
| `Esc` | 返回键 |
